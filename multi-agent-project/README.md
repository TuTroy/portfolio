# Multi-Agent Research Assistant
### 一个会团队协作的 AI 助手

> 用三个 AI Agent 协作完成研究任务——规划、搜索、写作，像一个真实的研究团队。

---

## 🎯 项目简介

**背景：** 传统 AI 助手是「单兵作战」，本项目实现了一个「Multi-Agent 协作系统」，多个 AI Agent 分工明确、协作有序。

**效果：** 输入一个研究主题，比如「AI 应用工程师的薪资和技能要求」，系统会自动：
1. 拆解任务
2. 并行搜索信息
3. 整理并生成报告

## 📌 技术细节

### Agent 提示词设计

**规划 Agent（Planner）**
> 你是一个专业的研究规划师。理解用户的研究主题，将其拆解为 3-5 个具体的搜索子任务，每个任务要有明确的搜索关键词。

**搜索 Agent（Researcher）**
> 你是一个专业的信息搜索专家。使用搜索工具收集高质量的参考资料，返回结构化的搜索结果。

**写作 Agent（Writer）**
> 你是一个专业的研究报告撰写师。把收集到的信息整理成一份结构清晰的研究报告，包含：背景、核心发现、分析、结论。

## 🎤 面试这样说

**Q: 这个项目是怎么设计的？**

> 我设计了一个三层级的 Multi-Agent 协作系统。规划 Agent 先理解用户意图，把任务拆解成子任务；搜索 Agent 并行执行，收集相关信息；写作 Agent 最后整理汇总成报告。这种分层设计让每个 Agent 职责单一，降低了复杂度，也方便扩展。

**Q: Agent 之间怎么通信的？**

> 通过共享上下文。每个 Agent 的输出会作为下一个 Agent 的输入，类似流水线。CrewAI 框架帮我处理了大部分的上下文传递和结果汇总。

**Q: 遇到过什么问题？**

> 早期搜索结果重复度很高，后来我在规划 Agent 层加了去重逻辑，要求它保证关键词的多样性。另外早期输出报告太长，通过限制每个子任务的结果数量解决。
