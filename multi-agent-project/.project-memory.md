## 🤖 三个 Agent 设计

### 1. Planner（规划 Agent）
- 调用 LLM 将研究主题拆解为 3-5 个子任务
- 输出 JSON 格式的子任务列表

### 2. Researcher（搜索 Agent）
- 调用 DuckDuckGo 搜索每个子任务
- 汇总搜索结果

### 3. Writer（写作 Agent）
- 调用 LLM 将搜索结果整理为结构化报告
- 输出：背景、核心发现、分析、结论
