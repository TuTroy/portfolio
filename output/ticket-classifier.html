客服工单智能分类助手

🤖 LLM / RAG / LangChain / FastAPI 📅 2026 ⏱️ 进行中

项目概述

基于 LLM + RAG 构建客服工单分类与回复推荐系统，日均处理工单1200+，分类准确率91%。通过检索增强生成技术，结合企业历史工单知识库，实现智能分类和推荐回复。

技术架构

  • LLM：调用 GPT / Claude 系列模型
  • RAG：LangChain + Chroma 向量数据库
  • 知识库：历史工单 + 产品文档
  • API：FastAPI 提供推理接口

核心成果

  • 日均处理 1200+ 工单
  • 分类准确率 91%
  • 客服响应效率提升 40%
